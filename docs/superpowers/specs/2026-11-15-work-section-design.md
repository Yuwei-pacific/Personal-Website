# 首页 Work 区：墨线串起作品、封面在墨里显影

日期：2026-11-15
样稿：`src/app/(site)/[locale]/mockup-work/`（临时，正式实现后删除）

## 为什么做

首屏已经按新的视觉识别落地：墨与纸、会呼吸的五色晕、鼠标划过像筷子划开油。但首屏之后的部分还是旧样子。
Work 区是访客看完首屏后的主要内容，也是作品集的主体，所以先改它，并在这里定下后面各页沿用的规则。

用户对这一块的要求（原话整理）：

- 访客滚到这里，要对项目有一个大致的了解，看到感兴趣的可以点进详情。
- 这里放的是不同的 case study，合起来要体现设计、开发、思考的综合能力。
- 要有 VI 里那种彩色流动的墨，不能只是换了字体和颜色的常见作品集模板。

## 目标

1. **墨线串起作品**：一根墨线从作品区顶部流进来，往下蜿蜒，流过每个精选作品，最后变成目录顶上那道线，横穿出页面。
2. **在墨里看作品**：每个精选作品是一滩化开的墨，封面显在墨最浓的地方。图像外面先是一圈墨，再往外是五色的晕。墨滩边缘会呼吸，鼠标划过时，图像像油一样被推开，然后合回来。
3. **一次只化开一处**：离视口中线最近的那个精选作品是焦点。只有它完整化开、带五色晕、封面是彩色；有封面视频时，在墨里自动播放。其他作品只留一圈干净的墨边，封面是黑白静止的，墨线也收成一根素黑细线。滚动时，焦点从一个作品渐变到下一个，约 0.45 秒。
4. **精选 + 目录**：精选作品（在 Sanity 里勾选）大幅展示，其余项目进目录，一行一个。悬停某一行时，旁边落下一小滩墨，里面显出这个项目的封面；有视频就播放视频，彩色，约 0.9 秒漫开。
5. **后台可控**：首页精选在 Sanity 里勾选，不用改代码。

## 不做的事

- 不改首页的区块顺序：仍然是首屏 → About 简介 → Work（用户决定）。所以墨线在作品区顶部重新开始，不和首屏的墨线相连。
- 不改项目详情页、About、页脚。它们之后再做，沿用这里定下的规则。
- 不做按角色筛选目录。项目多了以后再考虑。

## 反目标（做到了也算失败的情况）

- **太花、太满**：每一屏不能同时有多处带五色晕的墨。作品区的主角是封面，晕只贴着墨滩一圈（用户看过「满版大墨滩 + 宽晕」的版本，认为太花）。
- **墨线像电缆或霓虹灯管**：不能是直线斜拉，也不能粗细一路相同（用户看过，认为丑和突兀）。
- **公式化的排版**：不能退回规整的卡片网格。
- **掉帧**：滚动和划动时要保持流畅。

## 约束

- 品牌手册：一个画面只化开一处（首屏是例外）。作品区靠「焦点」机制遵守这条。
- 强调色只用在线和点上，不用在文字上；Geist 只用 Regular；Fraunces 只用于大标题。
- CMS 是唯一的内容来源；过滤和排序只在 GROQ 里做；查询都放在 `src/sanity/queries.ts`，改了要运行 `npm run typegen`。
- 首页的区块是叠纸（`Sheet`），每张纸至少一屏高。
- 封面和视频来自 `cdn.sanity.io`。上传成 WebGL 纹理要带 `crossOrigin="anonymous"`，Sanity CDN 支持跨域；CSP 已经允许这个域名的 `img-src` 和 `media-src`。
- 每个动效都要单独照顾「减弱动画」设置。

## 考虑过的方案

| 方案 | 说明 | 结果 |
| --- | --- | --- |
| A 展签 / B 墨与纸 / C 编辑式目录 | 三种常规版式。B 是封面默认黑白、悬停才着色 | 用户否决：都没体现 VI 的流动墨水，排版公式化 |
| 1 一根线串起作品 | 首屏墨线延续成串起项目的线 | **采用**（与 2 结合） |
| 2 在墨里看作品 | 封面从一滩化开的墨里显出来 | **采用**（与 1 结合） |
| 3 平时安静，悬停才化开 | 只在交互时化开 | 未采用；它的「悬停化开」思路用在了目录预览上 |

样稿迭代中定下的细节：

- 墨滩缩小一号（桌面占 5 / 12 列）；晕比首屏收一档。
- 墨线是 S 形往下流淌：竖直流出、竖直流进，从墨滩靠来路、去路的一侧进出；靠近墨滩处粗，中段收细。
- 封面黑白 / 彩色、视频播放跟随焦点（用户提出）。
- 目录悬停出现墨滩预览（用户提出）。

## 已定的做法

### 数据（Sanity）

- **新增「首页精选」开关** `featured`（boolean，默认关），放在 Overview 分页。
- **新增「精选顺序」** `featuredOrder`（number，只在勾选精选后显示）。精选按它升序排，相同时按年份倒序。
- **精选最多 4 个**：渲染器一次最多处理 4 个焦点区域。勾到第 5 个时，Studio 显示提醒但允许保存，第 5 个以后进目录。*（之前跟用户说的是 5 个以上才提醒，这里改成 4，需要告知用户。）*
- **删除 Project visibility**：从 schema 里去掉 `visibility` 字段，并删掉 `queries.ts` 里 5 处 `visibility != false` 过滤。不想公开的项目直接撤回成草稿（用户决定）。现有 5 个项目都是可见的，所以网站内容不变。
- 首页查询增加 `roles`（取 `roleTranslations`，按 locale 解析）、`featured`、`featuredOrder`。`Project` 视图模型增加 `roles: string[]` 和 `featured: boolean`。精选与目录的拆分在 GROQ 里完成：一次查询返回 `{ featured: [...], index: [...] }`，组件里不再过滤或排序。
  - `featured`：勾选了精选的项目，按 `featuredOrder` 升序、再按年份倒序排，取前 4 个（`[0...4]`）。
  - `index`：其余所有项目，包括超出 4 个的精选，按年份倒序排。写法是 `!(_id in <上面那个子查询>._id)`。
- 网站读的是 published 视图（`fetch.ts` / `client.ts`），草稿本来就不会出现。所以撤回成草稿就等于隐藏，这正是去掉 visibility 的前提。
- 编号是连续的：精选是 01–0n，目录接着往下编。
- 空状态：没有勾选任何精选时，只显示目录（不会空着）；一个项目都没有时，沿用现有的 `home.projects.empty` 文案。

### 版式（桌面，md 及以上）

- 区块标题：Fraunces 大字「Work」加作品总数（沿用字典里的 `home.projects.title` 和 `countLabel`）。
- 精选作品：左右交错排列。封面占位 5 / 12 列，文字 4 / 12 列，按三种位置循环（同样稿）；各项之间留大段空白给墨线。
  文字依次是：编号（Fraunces 斜体、淡墨）、标题（Fraunces）、一句话简介、`My roles` 用「·」连接 + 年份。
- 目录：标题「Index」加项目数；墨线落成顶上那道线。每行是编号、标题（Fraunces）、类型、年份、箭头。悬停时，标题右移一点，同时出现墨滩预览。

### 版式（手机，md 以下）

- 单列：每个精选是全宽的墨滩加下方文字。墨线在相邻两滩墨之间竖直流淌，S 形幅度小一些。焦点仍按视口中线判断，所以手机上也是「滚到哪个，哪个化开、着色、播视频」。
- 目录没有悬停预览，点一行直接进入详情页。

### 渲染（`src/components/ui/ink/`）

样稿已经在渲染器里加了下面这些能力，正式实现时整理、补注释后保留：

- `drawImage`：墨芯里显出图像。图像只跟着筷子的位移移动，不跟着噪声抖动。
- `focusRegions` 加 `setFocus(index)`：焦点之外收成墨边、图像变黑白。焦点权重随时间缓动。
- `setVideo(video, rect)`：化开时在墨里播放视频，按 object-fit: cover 裁切；一次只播一个。
- 显影参数：可调时长、开头停顿，以及每次换形状都重新显影（用于悬停预览）。
- `maxDpr`：作品区画布很高，像素密度上限设为 1.5。

作品区本身：

- 一块 `InkSurface` 铺满整个 Work 区（`absolute inset-0`）。形状按占位元素的位置画：`[data-ink="cover"]` 是封面，`[data-ink="rule"]` 是目录顶线。尺寸和位置一变就重算。
- 墨滩：围绕封面占位外扩 32px 的超椭圆，边缘带少量起伏；封面按 object-fit: cover 画进墨滩，并裁成墨滩的形状。
- 墨线：采样点组成的曲线，每个采样点带一个粗细系数，横截面渐变按多遍笔画叠出来。参数沿用样稿：晕带半高 20 个单位、墨芯 4px 等。
- 焦点：滚动时（每帧最多一次）选出离视口中线最近、且距离在 0.55 个视口高度以内的精选作品；没有符合的就是 -1，都收拢。
- 视频：只为焦点作品创建 `<video>`（muted、loop、playsInline、crossOrigin），失去焦点就暂停。

### 交互与状态

- 点击精选或目录行进入详情页。保留现有的「封面共享过渡」：占位里放一张隐藏的彩色 `<img>`，点击时显示它并认领过渡名，从它变形到详情页的封面。
- 键盘：目录行获得焦点时同样显示预览；精选作品是整块可点击的链接，`aria-label` 为项目标题。封面的替代文字放在占位里，用 sr-only。
- 减弱动画：只画静止的一帧；焦点切换不过渡，直接切换；不播放视频；没有悬停预览的显影动画。

### 降级（不支持 WebGL2）

`InkSurface` 不渲染画布。封面占位里显示普通 `<img>`（圆角，焦点之外用 CSS 灰度），没有墨线，目录悬停显示普通图片。

## 留给实现者决定的

## 实现时的验收

- `npm run check` 与 `npm run smoke` 通过。
- 浅色、深色两种主题；1440、1024、768、375 四种宽度。
- 焦点切换、视频播放与停止、目录悬停预览、划动后能完全合回。
- 帧率：滚动并持续划动时，与首屏同级，在 120Hz 屏上不掉帧；用 GPU 计时确认作品区每帧在 2ms 以内。
- 在 Sanity 里勾选或取消精选、调整顺序后，首页按预期变化。
