# 项目详情页：编辑式长卷

## 为什么

首页和 About 已经是编辑式版面（贴边大字、编号、不对称网格），详情页还是居中窄栏的堆叠模板：
正文一行 150+ 字符、首屏没有重点、最重要的外链最弱、看完没有去处。

## 目标

- 首屏 30 秒看懂：标题、简介、我的角色、类型/年份/客户/地点、外链都在第一屏。
- 正文可读：编号小标题在左栏，正文限宽在右栏，媒体横跨。
- 页面有结尾：下一个项目。
- 不改 Sanity schema 和已有内容。

非目标：重写项目内容、画廊去重、图文模块按比例自动左右并排（等内容定稿后再议）。

## 方案

考虑过三种：

- **A 编辑式长卷**（选定）：延续首页语言，文字和媒体交替推进。
- B 影像优先：封面占满首屏、文字最少。封面多为网站截图，撑不起全屏。
- C 粘性侧栏：信息效率最高，但观感像文档站，手机上退回堆叠。

A 借用 C 的一点：小标题在左栏吸顶。

## 设计

- **边距**：改用首页的 `px-edge`，不再 `max-w-content` 居中。
- **首屏**（浅色）：返回链接 → display 级标题（遮罩揭示）→ 左 6 列简介 + 大号文字外链，
  右 5 列元信息（我的角色放第一行）。
- **封面**：左右出血，压在深浅分界上，滚动时轻微视差。
- **正文**（深色）：12 列。带小标题的模块开启一个「章节」：上方细线，左 4 列编号 + 小标题（桌面吸顶），
  右 7 列正文（约 62 字符）。无标题的媒体/引用归入上一章节，间距更小；章节之间间距更大。
  图文模块：文字在上、媒体在下，同在右栏（暂不读取 mediaPosition）。
- **Credits**：同一套两栏；贡献说明 + 合作者/技能/外链。
- **画廊**：左对齐标题 + 数量，沿用现有组件。
- **下一个项目**：整块可点，编号 + 标题 + 类型 + 封面缩略图。顺序沿用首页列表（GROQ 已排序），
  末尾回到第一个；复用 `PROJECTS_QUERY`，不新增查询。
- **共享过渡**：首页卡片封面 / 下一个项目缩略图 → 详情页封面，用 `view-transition-name`。
  只给被点击的那一张命名，避免同名冲突；减弱动画时关闭。
